# AGENTS.md — laim-kriteria-selector

Репозиторий одной ноды Sber DS контура LAIM (Live AI Monitoring).

- **Нода самодостаточна.** Никаких импортов извне каталога; `descriptor.json`
  перечисляет все исходники в `sourceFiles`. База платформы — `py312-simple`:
  синтаксис и stdlib новее Python 3.12 не использовать.
- **Ветки.** Рабочая ветка — `dev`. Каждая правка — тематическая ветка
  `fix/*`, `chore/*` или `docs/*` от рабочей, один коммит — одна задача,
  влитие через `--no-ff`.
- **Гейт качества.** CI (`.github/workflows/ci.yml`: ruff, pytest) обязан
  быть зелёным до влития. Локально: `ruff check .` и `python -m pytest -q`.
- **TDD.** Сначала тест, воспроизводящий дефект или контракт, затем
  минимальная правка. Тесты не ослаблять и не пропускать ради зелёного прогона.
- **README — контракт деплоя.** Любое изменение поведения (порт, настройка,
  деградация, код причины) отражается в README тем же коммитом.
- **Стиль.** Идентификаторы английские; docstrings, комментарии, сообщения
  логов и ошибок — русские; в выводе ноды нет эмодзи. Минимум кода, решающий
  именно поставленную задачу: без абстракций «на будущее» и мёртвого кода.
- **Сообщения коммитов** на русском: строка «что сделано» до 72 символов,
  в теле — зачем.
